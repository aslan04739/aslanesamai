Google prend désormais en charge les résultats enrichis pour les contenus payants

Aslane Samai
19 septembre 2023

Google adopte les contenus payants

Google a enfin béni, ou du moins accepté, les contenus payants.

Eh oui : dans une récente publication sur Twitter / X, Google a annoncé via son compte Search Central que les résultats enrichis de la SERP prendront désormais en charge la validation des données structurées pour les contenus payants.

En clair, Google indiquera aux internautes, directement dans la SERP, si un contenu est derrière un paywall, pour leur faire gagner du temps et des efforts.

En quoi cela aide-t-il les SEO ?

Ce changement aide les SEO de plusieurs façons, notamment pour :

  1. toucher l'audience ciblée ;
  2. réduire les clics suivis d'un retour immédiat ;
  3. aider Google à mieux comprendre leurs contenus.

Comment le mettre en place ?

Ajouter des données structurées pour un contenu payant se fait comme pour d'autres types de contenus (articles de blog, événements, etc.) : de préférence en JSON-LD, puis on vérifie le balisage une fois terminé.

                   {
                   "@context": "https://schema.org",
                   "@type": "NewsArticle",
                   "mainEntityOfPage": {
                   "@type": "WebPage",
                   "@id": "https://example.org/article"
                   },
                   (...)
                   "isAccessibleForFree": "False",
                   "hasPart": {
                   "@type": "WebPageElement",
                   "isAccessibleForFree": "False",
                   "cssSelector": ".paywall"
                   }
                   }

Quels types de contenus peut-on placer derrière un paywall ?

Vous pouvez ajouter des données structurées à de nombreux types de contenus payants, par exemple :

  • Article
  • NewsArticle
  • Blog
  • Comment
  • Course
  • HowTo
  • Message
  • Review
  • WebPage

Enfin, Google a précisé que la SERP SGE (la nouvelle SERP pilotée par l'IA) renverra vers des contenus payants s'ils sont jugés pertinents. Les internautes auront le choix de cliquer ou non.
