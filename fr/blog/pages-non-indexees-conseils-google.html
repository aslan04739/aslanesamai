Vos pages ne sont pas indexées ? Voici ce que recommandent les équipes de Google

Aslane Samai
15 juin 2023

On a tous rencontré un jour des problèmes d'indexation. Et quand ça arrive, le diagnostic peut être compliqué, parce qu'on ne sait pas forcément d'où vient le problème. Heureusement, la question a été posée directement aux cadres de Google.

Distinguer indexation et positionnement (visibilité dans la SERP)

Le premier point important soulevé par Gary, John et Martin est la différence entre une page indexée et une page visible. Selon eux, la plupart du temps, les pages sont correctement indexées, mais ne se positionnent simplement pas.

Si vous ne savez pas si votre page est indexée, vérifiez-le dans la Google Search Console (Pages ⇒ pages indexées, ou collez l'URL dans la barre de recherche).

Ce point réglé, passons en revue les obstacles qui peuvent empêcher une page d'être indexée.

La page n'a pas été explorée

Pour être indexée, votre page doit d'abord être découverte par les robots de Google. Vous pouvez vérifier si elle a été explorée dans la Google Search Console : allez dans Pages ⇒ Raisons pour lesquelles les pages ne sont pas indexées.

Un problème plus large, ou différent

Si toutes vos pages, ou la plupart, ne sont pas indexées, le problème dépasse sans doute l'indexation d'URL individuelles :

  • un serveur inaccessible ;
  • une mauvaise utilisation du robots.txt ;
  • un problème de contenu : contenu trop mince, page vide, etc. ;
  • une page sans liens : une page orpheline que les robots n'ont aucun moyen de découvrir ;
  • la canonicalisation ;
  • une demande de suppression manuelle (certains demandent la désindexation de tout leur site) ;
  • d'anciens contenus spammy sur le site (site sur liste noire) ;
  • des différences d'indexation entre les versions avec et sans www ;
  • une version canonique de votre site déjà indexée ;
  • une balise noindex sur votre page ;
  • les pages « bientôt disponible », qui ne seront pas indexées.

Combien de temps attendre avant de s'inquiéter de l'indexation ?

Selon les trois experts, le délai d'indexation varie. Cela dit, Google indexe généralement les pages assez vite quand il est pertinent que le contenu soit sur le web.
